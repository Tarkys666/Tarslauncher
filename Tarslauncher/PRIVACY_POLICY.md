# TarsLauncher Privacy Policy

**Last Updated:** August 30, 2025  
**Effective Date:** August 30, 2025

## 1. Introduction

TarsLauncher ("app", "we", "us", "our") is committed to protecting your privacy and ensuring transparency about how we handle your personal information. This Privacy Policy explains what information we collect, how we use it, and your rights regarding your personal data when you use the TarsLauncher Android application.

**By using TarsLauncher, you agree to the collection and use of information in accordance with this policy.**

## 2. Information We Collect

### 2.1 Personal Information (Pro Version Only)

**Google Account Information:**
- Email address
- Google account ID  
- Display name
- Profile picture (if provided)
- **Purpose:** Pro version authentication, license verification, and user support
- **Legal Basis:** Contract performance (Pro version purchase)
- **Retention:** Until Pro subscription is cancelled or account is deleted

### 2.2 Application Data

**Installed Applications List (QUERY_ALL_PACKAGES Permission):**
- Names of installed applications
- Package names
- Application icons
- Installation dates
- **Purpose:** Display applications in launcher interface and app drawer
- **Storage:** Locally on your device only - never transmitted or shared
- **Legal Basis:** Legitimate interest (core launcher functionality)

### 2.3 System Permissions & Usage

**Wallpaper Management (SET_WALLPAPER Permission):**
- Access to change device wallpaper
- **Purpose:** Enable wallpaper customization features
- **Usage:** Only when explicitly activated by user

**Device Administration (BIND_DEVICE_ADMIN Permission):**
- Permission to lock device screen
- **Purpose:** Double-tap to lock screen functionality
- **Usage:** Only when feature is enabled by user

**Internet Access (INTERNET Permission):**
- Network connectivity for Pro features
- **Purpose:** Google authentication, license verification, cloud sync
- **Usage:** Only for Pro version features

### 2.4 Device & Technical Information

**Automatically Collected:**
- Device model and manufacturer
- Android operating system version
- Application version and build number
- Device language and region settings
- Screen resolution and density
- Available storage space
- **Purpose:** App optimization, compatibility, technical support, crash reporting
- **Legal Basis:** Legitimate interest (app functionality and improvement)

### 2.5 Purchase & Billing Information

**Google Play Billing Data:**
- Purchase tokens and order IDs
- Transaction dates and amounts
- Subscription status and renewal dates
- Refund and cancellation history
- **Purpose:** License verification, subscription management, customer support
- **Retention:** As required by tax laws and Google Play policies (typically 7 years)

### 2.6 Usage Analytics (Optional)

**App Usage Statistics:**
- Feature usage frequency
- Performance metrics
- Crash reports and error logs
- **Purpose:** App improvement and bug fixes
- **Control:** Can be disabled in app settings
- **Storage:** Anonymized and aggregated data only

## 5. Data Security & Protection

### 5.1 Security Measures
- **Encryption:** All sensitive data encrypted in transit (TLS 1.3) and at rest (AES-256)
- **Access Control:** Strict access controls and authentication for our systems
- **Regular Audits:** Periodic security assessments and vulnerability testing
- **Secure Infrastructure:** Google Cloud Platform with enterprise-grade security
- **Data Minimization:** We collect only necessary data for stated purposes

### 5.2 Data Storage & Retention

**Local Storage:**
- App preferences and settings stored encrypted on your device
- Application lists never leave your device

**Cloud Storage (Pro Users Only):**
- Stored in Google Firebase (Europe region: europe-west1)
- Compliant with GDPR and other data protection regulations
- Automatic backups with 30-day retention

**Retention Periods:**
- Pro account data: Until subscription cancellation + 90 days
- Support communications: 3 years
- Purchase records: 7 years (tax compliance)
- Analytics data: 26 months (anonymized)
